以上使用已有V1.0即时存档及持久存档作为隔离测试夹具；即使样本字段对应，也**不证明V1.33已经在mGBA加载这些存档或完成游戏内保存重载**。私人报告保存在忽略的diagnostics，本次没有写入用户游戏、ROM或存档。

自动化同时扩展到V1.33的Lua/TCP写入、PP/性别、经济/背包、PC编辑/移动、全盒排序、引用批量、盒名、礼物及条件恢复；新增连接自动选版、配置身份错误、代码守卫变化和跨版恢复拒绝测试。最终测试/构建结果见[开发状态](development-status.md)及[发行日志](releases/v0.2.15.md)。

## 复现与使用

安装requirements-research.txt后，用自己的ROM与即时存档执行：

```powershell
python tools/extract_profile.py '你的V1.33.gba' --output diagnostics/profile-v133.json
python tools/verify_release.py '你的V1.33.gba' '你的即时存档.ss1' --all --report diagnostics/v133-release.json
python tools/verify_creation.py '你的V1.33.gba' '你的即时存档.ss1' --report diagnostics/v133-creation.json
python tools/verify_sidequests.py --rom '你的V1.33.gba' --state '你的即时存档.ss1' --report diagnostics/v133-sidequests.json
python tools/verify_box_names_repel.py '你的V1.33.gba' '你的即时存档.ss1' '你的配对存档.sav' --report diagnostics/v133-box-names-repel.json
```

使用0.2.15完整便携包；在mGBA载入V1.33及独立存档副本，重载本包mercury_bridge.lua后连接，标题应识别1.33。先验证读取与少量修改、读回、游戏内保存/重开和条件恢复，再使用批量操作。切换ROM须重新连接/选存档，重新关联本地盒锁；勿用旧即时存档覆盖刚保存的进度。保存重载、自然孵化、跨日事件、完整菜单与旧存档迁移仍待实机核验。
