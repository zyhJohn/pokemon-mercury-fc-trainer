# Gen III 存档与内存结构速查

## 1. GBA ROM 头

| 偏移 | 大小 | 字段 |
|---|---|---|
| `0xA0` | 12 | 游戏标题（ASCII） |
| `0xAC` | 4 | 游戏代码（如 `BPRE`=火红 US） |
| `0xB0` | 2 | 厂商码 |

## 2. 存档文件（128KB Flash）

```
0x000000  存档块 A（14 扇区 × 4096B）
0x00E000  存档块 B（14 扇区 × 4096B）
0x01C000  殿堂
0x01E000  神秘礼物
0x01F000  战斗记录
```

- 每扇区 = 3968B 数据 + 128B 尾部。
- 尾部：`0xFF4` section ID(u16)、`0xFF6` 校验和(u16)、`0xFF8` 签名 `0x08012025`、`0xFFC` 存档索引(u32)。
- 存档索引更大者为最新存档块；每块含 section 0~13，顺序轮转。
- section 0 = 训练师信息，section 1 = 队伍/道具，section 2 = 游戏状态。
- 训练师信息(section0)：名字 `0x0000`(7B)，性别 `0x0008`，TID `0x000A`(4B=公开ID|秘密ID<<16)，时长 `0x000E`(5B)，security key `0x0AF8`(4B，副本 `0x0F20`)。
- 队伍/道具(section1)：队伍数量 `0x0034`，队伍 `0x0038`(6×100B)，金钱 `0x0290`(u32)，代币 `0x0294`(u16)，PC道具 `0x0298`，道具口袋 `0x0310`。

## 3. 火红(BPRE) 关键内存地址（原版 vs 某改版实测）

| 名称 | 原版 | 改版实测（水银FC） |
|---|---|---|
| `gSaveBlock1Ptr` | `0x03005008` | `0x03005008` |
| SaveBlock1 基址 | ~`0x020255A8` | `0x0202552C` |
| 金钱 | `0x02025838` | `0x020257BC` |
| 代币 | `0x0202583C` | `0x020257C0` |
| 队伍 | `0x02024284` | `0x02024284`（不变） |
| 队伍数量 | `0x02024029` | `0x02024029`（不变） |
| 经验相关 | `0x02023D50` | 不变 |
| 背包道具口袋 | — | `0x0203BB20` |

> 规律：改版把 SaveBlock1 前移 0x7C，故 `SaveBlock1 + 0x290` 的金钱随之移动；队伍/经验不在 SaveBlock1 内，不受影响。

## 4. 队伍宝可梦（100 字节，每只）

| 偏移 | 大小 | 字段 |
|---|---|---|
| 0x00 | 4 | 性格值 personality |
| 0x04 | 4 | OT ID |
| 0x08 | 10 | 昵称 |
| 0x12 | 2 | 语言 |
| 0x14 | 7 | OT 名 |
| 0x1C | 2 | 校验和（security key=0 时恒 0） |
| 0x20 | 48 | 4 子结构 × 12B |
| 0x50 | 4 | 状态 |
| 0x54 | 1 | 等级 |
| 0x56 | 2 | 当前 HP |
| 0x58 | 2 | 最大 HP |
| 0x5A~0x62 | 2×5 | 攻击/防御/速度/特攻/特防 |

## 5. 子结构顺序（personality % 24）

```
0:GAEM 1:GAME 2:GEAM 3:GEMA 4:GMAE 5:GMEA
6:AGEM 7:AGME 8:AEGM 9:AEMG 10:AMGE 11:AMEG
12:EGAM 13:EGMA 14:EAGM 15:EAMG 16:EMGA 17:EMAG
18:MGAE 19:MGEA 20:MAGE 21:MAEG 22:MEGA 23:MEAG
```

Growth 子结构：`0` 物种(u16)，`2` 携带道具(u16)，`4` 经验(u32)，`8` PP加成(u8)，`9` 亲密度(u8)。

**解密**：原版子结构需 XOR `OTID ⊕ personality`；改版若 `security key=0` 且校验和恒 0，则为明文，直接读。

## 6. 背包道具口袋

- 地址（改版实测）：`0x0203BB20`，每格 4B = `[道具ID u16][数量 u16]`。
- 道具 ID 1~376 为原版（中文名见 names.json），>376 为改版扩展。
- 数量在 security key=0 时明文。
