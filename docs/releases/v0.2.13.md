# v0.2.13 · 全盒排序、本地盒锁与已有蛋周期归零

原始构建：2026-10-05（Asia/Shanghai）；2026-10-05补发历史Release。

## 本版更新

- 删除重复的一键转蛋按钮，蛋状态前置、亲密度移入基本/能力；四个招式保留，空招式默认0 PP并清除对应提升位，道具及资料库沿用原列表。
- 队伍基础组增加滚动，并修复窗口缩放时默认空wraplength标签的Tk异常。
- 盒子右键提供单只独立编辑窗口、“移动”和“快速生蛋”；仅对已有蛋启用周期归零，普通精灵和锁盒置灰，保留蛋状态。
- 全部未锁盒的精灵按内部物种/形态编号汇总稳定排序，再依次放回未锁盒；同号原顺序、完整58字节保留、空槽末尾。执行前弹窗告知全盒范围，提示先锁定不想移动的盒子，再确认变化盒数。
- 用户关联当前.sav后，盒锁按本地路径及ROM哈希保存在box-locks.json，不修改存档；重新打开后选择同一存档加载。后端拒绝锁盒编辑、移入/移出、排序及恢复。
- 新增整盒专用BOXBATCHCRC：统一比较全部参与盒与运行守卫，在同回调写入及读回；已确认备份支持最多25个整盒补丁条件恢复。普通事务容量不变，异常写入不承诺自动撤销。
- 游戏数值页集中队伍已有蛋周期归零和填满PP草稿入口；培育屋待领取蛋、喷雾步数及持续金手指仍待核验并置灰。
- 211项自动化、两版各750只全盒稳定排序与完整恢复、实际Lua/TCP大请求通过；两版各6队伍周期0、432组PC转换与6个PC周期0解压/取出/走路检测通过。

## 使用与验证范围

支持已核验水银V1.0/V1.2。必须关闭旧脚本会话并重载本包mercury_bridge.lua（BOXBATCH能力）。双栏引用暂存/Shift批量移动、盒名、礼物创建、空槽初始化、PP上限、玩家/宝可梦性别、劲敌及其余未核验字段仍未实现；完整孵化动画、保存重载仍待实机验收。

原包`build-info.json`记录自动化测试（含Lua）、可执行文件启动自检通过。本次发行核对ZIP完整性、包内文件哈希及原有提交，保留原始便携包，不重新打包；没有把原型、隔离函数验证或历史实机反馈等同于所有保存重载场景通过。所有写入沿用ROM检查、旧值比较、写前备份、读回和条件恢复；写入后仍需在游戏内保存。
