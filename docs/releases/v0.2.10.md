# v0.2.10 · 存档日历、星期与每日日期修复

原始构建：2026-10-03（Asia/Shanghai）；2026-10-05补发历史Release。

## 本版更新

- 新增时间/星期页：显示 RTC 日期、周一至周日、累计游玩时长和引擎每日刷新日期。
- 关闭游戏后可独占编辑.sav尾部 RTC 偏移，指定日期/时间、选择同周星期或校准到电脑时间；完整存档先备份，整文件比较及条件恢复。
- 累计时长独立修改，保留帧计数；新BATCHVERIFY能力在同次Lua回调读回，避免正常计时误报。
- 每日日期处于未来时，可预览并将已核实的Var5009/500A前移到当前游戏日期的前一天，让引擎执行当天刷新。
- 26组实际日历、4组计时、3组每日判断及持久section4位置对照通过；覆盖跨日/周/闰日、占用、过期和部分写入。

## 使用与验证范围

仅支持已核验水银 V1.0。.ss1等即时存档不由RTC文件操作修改；其他自定义周常/领取标志不自动重置，具体周日内容及保存重载待实机验收。须重载本版脚本。

原包`build-info.json`记录自动化测试（含Lua）、可执行文件启动自检通过。本次发行核对ZIP完整性、包内文件哈希及原有提交，保留原始便携包，不重新打包；没有把原型、隔离函数验证或历史实机反馈等同于所有保存重载场景通过。所有写入沿用ROM检查、旧值比较、写前备份、读回和条件恢复；写入后仍需在游戏内保存。
