# v0.2.12 · 导航调整与需求/恢复核查

原始构建：2026-10-05（Asia/Shanghai）；2026-10-05补发历史Release。

## 本版更新

- 正式导航改为“队伍 → 盒子编辑 → 训练师”，保留其他页及连接、刷新、道具编辑、诊断和恢复功能。
- 提供分组修订原型：四个招式、引用暂存、Shift逐只选择、右键编辑/批量移动流程与盒名/排序/锁盒演示。
- 登记用户确认的引用暂存原则和新增盒子要求；移除原型顶栏未实现且用途不明的通用导入占位。
- 逐项核查原需求，说明备份、旧值比较和条件恢复边界；增加盒间写入中断/读回失败的未确认备份故障注入。

## 使用与验证范围

支持已核验水银V1.0/V1.2，195项自动化通过。正式版的主要界面变化是导航；引用暂存、Shift批量移动、盒名/排序/锁盒当时仅为原型，不计为实现。

原包`build-info.json`记录自动化测试（含Lua）、可执行文件启动自检通过。本次发行核对ZIP完整性、包内文件哈希及原有提交，保留原始便携包，不重新打包；没有把原型、隔离函数验证或历史实机反馈等同于所有保存重载场景通过。所有写入沿用ROM检查、旧值比较、写前备份、读回和条件恢复；写入后仍需在游戏内保存。
