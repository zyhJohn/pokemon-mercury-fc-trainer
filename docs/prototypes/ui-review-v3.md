# 水银 FC 修改器 v3 交互原型审阅

[打开交互原型](mercury-editor-review-v3.html)。请从仓库根目录启动本地 HTTP 服务后访问 `docs/prototypes/mercury-editor-review-v3.html`，这样浏览器才能读取同仓库的 `sidequests.json` 和 `distributions.json`。例如 `python -m http.server 8765`，再打开 `http://localhost:8765/docs/prototypes/mercury-editor-review-v3.html`。原型不会连接模拟器，也不会写游戏或存档。

## 本轮请审阅

1. 导航保持“队伍 → 盒子编辑 → 训练师”优先，队伍左侧选个体、右侧按“基本 / 能力、招式 / PP、来源 / OT、形态”分组。道具仍为可筛口袋的列表；队伍展示四个招式。顶部保留连接、刷新、诊断、备份 / 恢复和独立神秘礼物入口，没有通用导入按钮。
2. 盒子仍是左侧引用暂存、右侧 25 盒。Shift 逐只多选，右键出现编辑、移动与已有蛋周期归零。锁盒阻止相关草稿。点击队伍或盒子的空槽会进入“自定义创建”；顶部也有独立创建页。创建表单分为基本与来源、四个招式、能力，目标可选盒子空槽、队伍空位或显式顶替。
3. 训练师页一次预览玩家姓名、TID、SID 和劲敌姓名；玩家性别保持只读。玩家资料与宝可梦原训练师资料分开。劲敌姓名可能被后续剧情重新赋值。游戏数值页可演示喷雾剩余步数 0～250，背包道具不变。
4. 支线表从仓库的 96 项 JSON 读取标题、地点、阶段流程、奖励、剧情详情与来源；详情可展开。搜索和“全部、完成、未完成、进行中”四种视图可操作。仅前三项赋予模拟状态，其余为“— 未读取”，不将未知当作未完成。神秘礼物从仓库的 7 项 JSON 读取，6 项有已核验模板可选，待核验项目不可投放。
5. 每项编辑先成为草稿，再点页脚“检查与预览 → 模拟应用”。“备份 / 恢复”仅在当前模拟数据仍匹配应用后状态时允许恢复，修改草稿会使预览失效。创建草稿带入球种、地点、四招式和六项 IV/EV；IV、EV 越界或合计超限会拒绝，生成后再改输入须重新生成。礼物可试盒子空槽、队伍空位和“填满队伍用于演示”后的显式顶替；顶替预览显示前后个体身份。取消弹窗不会投放。

原型使用真实任务与配信目录，但任务状态、宝可梦、背包、训练师数值、备份和投放结果都是模拟数据。玩家性别、相遇方式与培育屋待领取蛋仍置灰并注明待核验原因。正式版的实机显示、剧情改写和保存重载需要另行验收。
