# 宝可梦水银 FC 修改器

面向《宝可梦水银FC～致150年后的你》Version 1.0 和 mGBA 0.10.5 的本地修改器。新版按实际 ROM 与即时存档重新核对结构，通过 Lua 编辑运行中的游戏内存。

## 使用

1. 解压完整发布包，双击 `启动修改器.bat`。初次使用可选择 mGBA 和自己的 ROM，也可直接打开 `MercuryTrainer.exe` 连接已运行的游戏。
2. 进入游戏，在 mGBA 的 **工具 → 脚本（Tools → Scripting）** 窗口加载发布包中的 v3 `mercury_bridge.lua`。保持模拟器运行；暂停时 Lua 网络回调也会停止。可以停留在游戏菜单中。旧脚本只允许读取，建议先关闭旧脚本会话。
3. 点击“连接”，选择队伍成员或背包口袋。编辑后先“检查与预览”，再写入。游戏数据变化时会拒绝写入，刷新后重试。建议在非战斗状态编辑。
4. 写入前自动备份，写入后逐字节读回核对。“恢复备份”仅在当前数据仍等于那次修改结果时恢复，避免覆盖后续进度。

程序不包含 ROM、存档或模拟器。运行目录需可写，以保存 `backups/`。备份与诊断包含个人游戏数据。

连接失败时仍可“导出诊断”，保存错误和连接信息。写入后若游戏内页面显示未刷新，可关闭并重新打开该页面；修改器的读回核对针对实际内存。修改器不会代替游戏执行存档操作。

## 当前功能

- 队伍物种、等级、HP、携带道具；等级变化同步经验，IV/EV 或物种变化重算能力值。
- 闪光开关：保持性格、性别和普通特性选择；未知图腾保持字形。晃晃斑须显式选择重新生成花纹才能改变PID。
- 性格编辑：保持性别、闪光和普通特性选择，同步重算能力值；同样保护 PID 相关形态。
- 六项 IV/EV：IV 0～31，EV 单项 0～252、总和不超过 510；修改 IV 保留蛋及隐藏特性标志。
- 依物种选择普通/隐藏特性；四个招式与 PP 编辑，更换招式清除该槽 PP 提升次数。
- 本物种等级招式表与 TM/HM 兼容性提示；学习器盒显示由 ROM 映射确认的招式名称。
- 金钱与代币；五类背包口袋。重要道具隐藏数量，同一道具保留内部数量。
- 离线水银资料库：1432 条宝可梦/形态、298 条特性、666 条道具、1014 条招式；区分内部编号与全国图鉴号。
- 已加载 ROM 的 CRC32 与 41 处特征检查、比较后写入、备份、读回验证、条件恢复、诊断导出。
- 战斗中禁止写入宝可梦，防止队伍与战斗副本不一致；只读查看仍可使用。
- 25 个 PC 盒子、每盒30格选择；支持闪光、性格、IV/EV、未知图腾字形和已核实来源字段编辑，保留其余压缩数据。
- 玩家 TID/SID 与英文/数字姓名编辑；主角性别原始值只读，玩家修改不批量改变宝可梦原训练师。
- 队伍与 PC 亲密度、相遇地点/等级、捕获球、原训练师 TID/SID、姓名及性别。未知地点暂以原始编号显示。
- 队伍与PC蛋状态转换：同步两处标志，转蛋同步1级、经验、默认周期和相遇等级；取消蛋标记不代表执行自然孵化。
- 未知图腾字形选择（队伍与 PC）；保留性格、性别、闪光和适用的普通特性约束。本 ROM 的26为“!”、27为“?”。
- 小陨星核心颜色：队伍和PC均可选择，同步PID与形态编号，保留所选闪光、性格、特性与经验进度；普通PID编辑保留核心颜色。
- 晃晃斑花纹：加载游戏图像后显示当前/预览正面形象，队伍和PC均可显式重新生成，保留所选性格、闪光、性别和适用特性约束；生成与预览不会直接写入。
- 左侧队伍六格与 PC30格卡片，右侧数值编辑；连接后点击“加载游戏微缩图”显示当前ROM图像。图片缺失仍可编辑；键盘方向键选择，切换成员或重读时提示未写入修改。图像仅在本次会话保留。

姓名支持已核对的 GB2312 汉字、英文字母、数字、空格、连字符与英文单引号，总计最多7字节（汉字占2字节，最多3个汉字）。未支持或未知编码保持原样；超长输入会拒绝，不会截断。主角性别、劲敌姓名仍未开放编辑。PC 的物种变更仅开放小陨星核心颜色，不提供通用物种/等级/招式编辑、创建或转移。

## 关于合法性和 ID

**无需把一只宝可梦重新编码为一个 ID。** 本改版队伍成员是 100 字节数据，四个子结构采用固定明文顺序。PID 只是其中一个 32 位字段，闪光由 PID 与原训练师 ID 共同决定。IV/EV 是独立字段。

“检查通过”表示已实现的结构与数值检查通过，不是官方合法性认证。尚未验证遭遇/配信来源、PID 与 IV 的随机生成关联、闪光锁定和所有配招途径。详情与 ROM 证据见 [已验证布局](docs/verified-layout.md)。

## 验证状态

已完成本地 ROM 反汇编核对、现有即时存档六只成员的能力值与经验核对、口袋特征核对，以及 Python/Lua 自动化测试。树果袋、精灵球 ×164、第四格学习器盒、冲浪和怪力均与用户描述对应。

另在隔离的 ARM CPU 中执行本地 ROM 函数，完成盒内 179 只宝可梦解码、537 次盒内编辑后解压与取出计算、240 组队伍变体、1432 个物种能力值与特性槽、1432 份等级学习表、128 个学习器映射及 12224 个兼容性用例的对照。等级修改使用 ROM 的精确经验表，修正通用公式在 1 级及若干进阶等级的差异。

**2026-10-02 用户确认实机写入已验证。** 该结论来自用户反馈；尚未取得逐项测试清单，不能据此宣称保存重载、全部字段、PC 编辑与备份恢复均已实测。先前代理的独立图形控制和 GDB 验证失败只代表当时的测试环境限制。

连接成功后直接关闭修改器，脚本界面没有报错符合预期：修改器关闭连接，Lua 清理客户端并保留监听。重新打开修改器应能再次连接，不必重复加载脚本。没有报错不等于游戏已经保存；正在写入时关闭窗口会等待操作和备份记录完成。

## 开发与打包

Windows、Python 3.11+（含 Tkinter）：

```powershell
python trainer_gui.py
python -m pip install -r requirements-dev.txt
python -m unittest discover -v
python tools/build_release.py
```

发布目录为 `dist/`。打包会运行测试及可执行文件界面启动自检，核对 ZIP 文件清单与哈希，并在含中文和空格的独立解压目录再次启动自检。单独运行测试时缺少 `lupa` 会跳过 Lua 测试；正式打包要求已安装该依赖。

当前版本0.2.0；发布包`build-info.json`记录源码提交、是否存在未提交改动和文件哈希，便于换电脑后核对版本。

| 文件 | 职责 |
|---|---|
| `pokemon_data.py` | 固定结构、PID 搜索、IV/EV、能力值与招式检查 |
| `box_data.py` | PC 压缩记录解码及限定字段编辑 |
| `trainer_core.py` | 编辑计划、ROM 检查、备份与恢复 |
| `memory_client.py` / `mercury_bridge.lua` | 本地通信和比较后写入 |
| `trainer_app.py` / `trainer_gui.py` | 图形界面与启动入口 |
| `pokemon_selector.py` / `scrolling_form.py` | 图形槽位选择与可滚动数值表单 |
| `name_codec.py` | 有限姓名字符往返，未知编码原样保留 |
| `sprite_images.py` / `spinda_images.py` | 从当前ROM解码图像及花纹，不分发游戏图像 |
| `rom_profile.json` | 从已核对 ROM 提取的数值表和特征 |
| `wiki_catalog.py` / `catalog.json` | 离线资料解析与搜索 |
| `tools/extract_profile.py` | 从相同 SHA-256 ROM 复现数值表 |
| `tools/verify_state.py` | 即时存档只读验证 |
| `tools/verify_rom_routines.py` | 在隔离 ARM CPU 执行 ROM 函数进行对照；需额外安装 `unicorn==2.1.4` |
