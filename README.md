# 宝可梦水银 FC 修改器

面向《宝可梦水银FC～致150年后的你》Version 1.0 / 1.2 和 mGBA 0.10.5 的本地修改器。按完整ROM身份自动选择已核验配置，通过 Lua 编辑运行中的游戏内存；RTC 日历通过关闭游戏后的 `.sav` 尾部编辑。未知版本拒绝写入。

## 使用

1. 解压完整发布包，双击 `启动修改器.bat`。初次使用可选择 mGBA 和自己的 ROM，也可直接打开 `MercuryTrainer.exe` 连接已运行的游戏。
2. 进入游戏，在 mGBA 的 **工具 → 脚本（Tools → Scripting）** 窗口加载本次发布包中的 v3 `mercury_bridge.lua`。0.2.9排序需要带`BATCH8192`能力的新脚本，请关闭旧脚本会话并重新加载。保持模拟器运行；暂停时 Lua 网络回调也会停止。可以停留在游戏菜单中。
3. 点击“连接”，选择队伍成员或背包口袋。编辑后先“检查与预览”，再写入。游戏数据变化时会拒绝写入，刷新后重试。建议在非战斗状态编辑。
4. 写入前自动备份，写入后逐字节读回核对。“恢复备份”仅在当前数据仍等于那次修改结果时恢复，避免覆盖后续进度。

程序不包含 ROM、存档或模拟器。运行目录需可写，以保存 `backups/`。备份与诊断包含个人游戏数据。

连接失败时仍可“导出诊断”，保存错误和连接信息。写入后若游戏内页面显示未刷新，可关闭并重新打开该页面；修改器的读回核对针对实际内存。修改器不会代替游戏执行存档操作。

- 队伍与PC蛋状态转换：同步两处标志，转蛋同步1级、经验、默认周期和相遇等级；取消蛋标记不代表执行自然孵化。
- 未知图腾字形选择（队伍与 PC）；保留性格、性别、闪光和适用的普通特性约束。本 ROM 的26为“!”、27为“?”。

- 晃晃斑花纹：加载游戏图像后显示当前/预览正面形象，队伍和PC均可显式重新生成，保留所选性格、闪光、性别和适用特性约束；生成与预览不会直接写入。

玩家及OT姓名支持已核对的 GB2312 汉字、英文字母、数字、空格、连字符与英文单引号，总计最多7字节（汉字占2字节，最多3个汉字）；宝可梦昵称最多10字节。未支持或未知编码保持原样；超长输入会拒绝，不会截断。主角性别、劲敌姓名仍未开放编辑。PC 的物种变更支持已核对的小陨星颜色、颤弦蝾螈性格及六家族持物联动，不提供通用物种/等级/招式编辑或空槽创建；跨盒移动仅移动已有成员。

## 时间与星期操作

“时间 / 星期”页区分 RTC 日历与累计时长。日期、时间、星期一起校准，累计时长独立处理。

1. **RTC 日期 / 星期**：先关闭 mGBA 中的该游戏，选择本地 ROM 和游戏内保存的 `.sav`，点击“读取 .sav 时间”。可填写 `YYYY-MM-DD HH:MM:SS`，或选择同一周的星期；“校准到电脑时间”先填入预览。检查后点击“写入 RTC 修改”，再重新打开 ROM，从游戏内存档继续。校准采用实际写入时的电脑时间，偏移为零；指定时间随后正常推进。
2. **每日事件停在未来日期**：加载 0.2.10 的 Lua 脚本并连接，保持 mGBA 运行，点击“读取游戏时间”。未来的 Var5009/500A 日期可先预览，再点击“写入每日日期修复”，前移至当前游戏日期的前一天。随后在游戏内保存，重新进入地图或重开游戏，让游戏自行执行当天刷新。这只处理已核实的引擎记录，其他自定义周常与奖励领取标志未开放编辑；实际周日内容是否恢复需游戏内验收。
3. **累计时长**：保持 mGBA 运行，读取后填写小时/分/秒并写入，最后在游戏内保存。使用已填写的绝对时长，保留帧计数；Lua 在同一次回调中读回确认，避免正常计时导致误报。

RTC 修改需要带16字节尾部的128 KiB `.sav`，不修改 `.ss1` 等即时存档。mGBA 占用该文件时会拒绝写入；先备份完整存档和事务记录，读回核对，仅在整份文件仍等于修改结果时条件恢复。恢复 RTC 用时间页按钮，恢复累计时长/每日日期用顶部“恢复备份”。旧即时存档、自定义 RTC 覆盖和换电脑后的时区变化可能影响结果，使用相同本地时区并关闭自定义 RTC 覆盖。年份范围2000～2099；时间回拨不会自动清空每日历史。

## 关于合法性和 ID

**无需把一只宝可梦重新编码为一个 ID。** 本改版队伍成员是 100 字节数据，四个子结构采用固定明文顺序。PID 只是其中一个 32 位字段，闪光由 PID 与原训练师 ID 共同决定。IV/EV 是独立字段。

“检查通过”表示已实现的结构与数值检查通过，不是官方合法性认证。尚未验证遭遇/配信来源、PID 与 IV 的随机生成关联、闪光锁定和所有配招途径。详情与 ROM 证据见 [已验证布局](docs/verified-layout.md)。

## 验证状态

已完成本地 ROM 反汇编核对、现有即时存档六只成员的能力值与经验核对、口袋特征核对，以及 Python/Lua 自动化测试。树果袋、精灵球 ×164、第四格学习器盒、冲浪和怪力均与用户描述对应。

另在隔离的 ARM CPU 中执行本地 ROM 函数，完成盒内 179 只宝可梦解码、537 次盒内编辑后解压与取出计算、240 组队伍变体、1432 个物种能力值与特性槽、1432 份等级学习表、128 个学习器映射及 12224 个兼容性用例的对照。等级修改使用 ROM 的精确经验表，修正通用公式在 1 级及若干进阶等级的差异。

**2026-10-02 用户确认实机写入已验证。** 该结论来自用户反馈；尚未取得逐项测试清单，不能据此宣称保存重载、全部字段、PC 编辑与备份恢复均已实测。先前代理的独立图形控制和 GDB 验证失败只代表当时的测试环境限制。

连接成功后直接关闭修改器，脚本界面没有报错符合预期：修改器关闭连接，Lua 清理客户端并保留监听。重新打开修改器应能再次连接，不必重复加载脚本。没有报错不等于游戏已经保存；正在写入时关闭窗口会等待操作和备份记录完成。

## 开发与打包

Windows、Python 3.11+（含 Tkinter）：

```powershell
python trainer_gui.py
python -m pip install -r requirements-dev.txt
python -m unittest discover -v
python tools/build_release.py
```

发布目录为 `dist/`。打包会运行测试及可执行文件界面启动自检，核对 ZIP 文件清单与哈希，并在含中文和空格的独立解压目录再次启动自检。单独运行测试时缺少 `lupa` 会跳过 Lua 测试；正式打包要求已安装该依赖。

当前版本0.2.11；发布包`build-info.json`记录源码提交、是否存在未提交改动和文件哈希，便于换电脑后核对版本。V1.2提供游戏内虚拟时钟时，修改RTC尾部不会覆盖它；时间页会提示当前时钟来源。界面简化原型在`docs/prototypes/mercury-editor-preview.html`，整体改版等待用户审阅；空槽创建尚未开放。
